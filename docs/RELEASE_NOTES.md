# Release Notes

## v1.0 - 2026-11-08

### Added
- Added a command-line flashcard quiz that shows correct answers and a final score.
- Added a way to create and save new flashcards for later study.
- Added category-based question viewing and a category count breakdown.
- Added a deck summary showing the deck name and number of cards.

### Fixed
- No additional fixes are included in this documentation release.

### Changed
- Updated the project documentation to clearly describe the features available on `main`.

### Known limitations
- The separate `category_report` helper is incomplete (Issue #2). The menu's category breakdown uses a different working helper.
- The last-card menu action expects the deck to contain at least one card.
- Issue #1 remains open for acceptance-criteria verification. Open practice pull requests are not part of this release until merged.
